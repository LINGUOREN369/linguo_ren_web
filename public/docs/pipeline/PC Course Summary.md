# PC Course Summary — Precalculus (2026–27)

> The top of the planning stack: **course goals → units → days.** Read this before building or
> teaching any unit. Unit detail lives in each unit summary (PC Unit 2 Summary,
> PC Unit 3 Summary); pacing lives in PC Planning Sheet.

---

## Course goals

By the end of the course, students can:

1. **Analyze any function** from its equation or its graph: domain, zeros, sign, and behavior.
2. **Work with functions as objects:** combine, compose, invert, and transform them.
3. **Know the major families** (polynomial, rational, exponential, logarithmic, trigonometric):
   how each behaves and why.
4. **Model and solve real problems** with them: growth and decay, periodic motion, triangles.

**Where it comes from:** Algebra 2 ends with polynomials, which is where Unit 2 picks up.
**Where it leads:** Calculus, which assumes students can read a function's zeros, sign, and
behavior, and are fluent with inverses, exponentials, logarithms, and trigonometry.

## The course in one line

Every function family gets the same treatment (where it is zero, where it is undefined, how it
behaves, how to undo it, and how to move it), so that Calculus starts from functions students can
already read.

## The year's arc

## Threads across units

These are the connections worth naming out loud when the earlier end comes up:

- **Quadratics → polynomials.** Unit 1's quadratics are the first polynomials Unit 2 analyzes.
- **Sign charts.** Unit 2's zeros-and-sign question comes back whenever a later function has to be
  solved or graphed, and it is the first thing Calculus asks of a function.
- **Inverses.** Unit 3's inverses return as logarithms (the inverse of exponentials) in Unit 4 and
  as inverse trig functions in Unit 6.
- **Restricted domains.** Unit 3 restricts a domain to make an inverse exist; Unit 6 does the same
  to define inverse sine, cosine, and tangent.
- **Transformations.** Unit 3's key-point method is how exponential and log graphs (Unit 4) and
  sine and cosine graphs (Units 5–6) get graphed.

## How this is used day to day

- **Building a unit:** its unit summary names which course goals the unit serves and which threads
  it carries in from earlier units or sets up for later ones. After the unit is built, update its
  row above.
- **Opening Questions** revisit the previous class's core topic, so each day starts by retrieving
  the last one (fluency).
- **Practice sheets** repeat the same skills across 8 sets with new numbers (fluency through
  varied repetition).
- **Closing Questions** are big-idea questions answered in words, not by computing (connections,
  not procedures).
- **When a thread's earlier end comes up,** say where it goes next, so students see the course as
  one story instead of a list of topics.
